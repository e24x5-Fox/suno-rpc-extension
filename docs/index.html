Suno → Discord RPC

Политика конфиденциальности. Обновлено 13 сентября 2026 года.

Коротко: данные никуда не уходят с вашего компьютера. Расширение передаёт сведения о треке только приложению Suno RPC, запущенному на этом же компьютере, по адресу ws://localhost:6969. Сервера у автора нет, аналитики и рекламы нет.

Что делает расширение

Расширение читает, что сейчас играет в плеере на suno.com, и передаёт это приложению Suno RPC на вашем компьютере. Приложение показывает трек в вашем статусе Discord. Без запущенного приложения расширение бесполезно: отправлять данные некуда.

Какие данные обрабатываются

  • Сведения о треке со страницы Suno: название, исполнитель, ссылка на обложку и на трек, длительность, текущая позиция и признак паузы.
  • Спектр звука вкладки. Звук захватывается только для того, чтобы посчитать уровни частот для визуализаций. Сам звук не записывается и не сохраняется: наружу уходят только числа спектра.
  • Последнее состояние хранится в chrome.storage.local, чтобы окно расширения показывало текущий трек сразу при открытии.

Расширение не читает ваш аккаунт Suno, не трогает другие вкладки и сайты, не собирает историю просмотров, местоположение, переписку и платёжные данные.

Куда уходят данные

Только на ws://localhost:6969 — это ваш собственный компьютер. Соединение не выходит за пределы устройства, и у автора нет сервера, который мог бы что-то принять. Данные не продаются и не передаются третьим лицам. Что именно приложение показывает в Discord, решаете вы в его настройках; передачей статуса в Discord занимается приложение, а не расширение.

Разрешения

  • activeTab и tabCapture — захват звука вкладки Suno для подсчёта спектра.
  • offscreen — считать спектр в скрытом документе; в Manifest V3 обработка звука иначе невозможна.
  • alarms — будить служебный процесс, чтобы соединение с приложением не обрывалось, пока вкладка в фоне.
  • storage — хранить последнее состояние для окна расширения.
  • Доступ к suno.com — читать плеер только на этом сайте.

Дети

Расширение не предназначено специально для детей и не собирает данные о ком бы то ни было.

Изменения

Если политика изменится, новая версия появится на этой странице с новой датой. Исходный код открыт, и любые изменения видны в истории репозитория.

English summary

The extension reads what is playing in the player on suno.com — title, artist, cover and track links, duration, position, paused state — and computes an audio spectrum from the tab's sound for visualisations. It sends that to ws://localhost:6969, the companion Suno RPC application running on the same computer, which shows the track in the user's Discord status.

Nothing leaves the user's device. The author operates no server, and the extension contains no analytics, ads or third-party code. Captured audio is never recorded or stored — only frequency levels are passed on. The last known state is kept in chrome.storage.local so the popup can show the current track immediately. No data is sold or shared with third parties. Questions: GitHub Issues.
