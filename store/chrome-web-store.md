# Заявка в Chrome Web Store — Suno → Discord RPC

Всё, что нужно вставить в панель разработчика
(<https://chrome.google.com/webstore/devconsole>). Архив собирается командой
`python build.py` и лежит в `dist/suno-rpc-extension-<версия>.zip`.

> **Главная сложность этой заявки.** Расширение бесполезно без приложения Suno RPC
> на компьютере пользователя: оно шлёт данные на `ws://localhost:6969`. Проверяющий
> не станет ставить приложение, увидит расширение, которое «ничего не делает», и
> может отклонить его как нерабочее. Поэтому и в описании, и в примечании для
> проверяющего это сказано прямо, а в `store/screenshots/` лежит снимок окна
> расширения с подключённым приложением.

## Вкладка «Описание магазина»

**Название** (до 75 символов)

```
Suno → Discord RPC
```

**Краткое описание** (до 132 символов)

```
Показывает трек с suno.com в статусе Discord. Работает вместе с приложением Suno RPC на вашем компьютере.
```

**Категория:** «Развлечения» (Entertainment). Язык listing'а — русский.

**Подробное описание**

```
Расширение показывает друзьям в Discord, что вы слушаете на Suno: название трека,
исполнителя, обложку и полосу времени.

ВАЖНО: НУЖНА ПРОГРАММА НА КОМПЬЮТЕРЕ

Одно расширение ничего не показывает. Discord принимает статус только от
программы, запущенной на том же компьютере, поэтому расширение передаёт данные о
треке приложению Suno RPC — бесплатному и с открытым исходным кодом:

    https://github.com/e24x5-Fox/suno-discord-rpc

Установите приложение, запустите его, откройте suno.com — и статус появится.
Значок расширения показывает, подключено ли оно: «🟢 Подключён» — приложение
отвечает, «▶ Играет» — трек найден и передаётся.

ЧТО ПЕРЕДАЁТСЯ

• Название трека, исполнитель, ссылка на обложку и на трек
• Позиция и длительность воспроизведения, признак паузы
• Спектр звука вкладки — для аудио-визуализаций в приложении

Всё это уходит только на ваш собственный компьютер, по адресу
ws://localhost:6969. Сервера у автора нет.

ПРИВАТНОСТЬ

Ни аналитики, ни рекламы, ни сторонних библиотек. Звук вкладки не записывается:
из него считаются только уровни частот. Исходный код открыт:

    https://github.com/e24x5-Fox/suno-rpc-extension
```

## Вкладка «Конфиденциальность»

**Единственное назначение** (Single purpose)

```
Расширение делает одно: читает сведения о треке, играющем на suno.com, и передаёт
их приложению Suno RPC на том же компьютере, чтобы оно показало трек в статусе
Discord.
```

**Обоснование разрешений**

| Разрешение | Обоснование |
|---|---|
| `activeTab` | Захват звука вкладки Suno разрешён только для вкладки, на которой расширение задействовано. Без этого разрешения `tabCapture` не может получить поток. |
| `tabCapture` | Звук нужен для подсчёта спектра частот, который приложение рисует в визуализациях. Сам звук не записывается и не сохраняется — наружу уходят только числа уровней. |
| `offscreen` | В Manifest V3 у служебного процесса нет доступа к Web Audio API. Спектр считается в скрытом документе — это единственный предусмотренный Chrome способ. |
| `alarms` | Служебный процесс выгружается примерно через 30 секунд простоя и уносит с собой соединение с приложением. Будильник раз в минуту не даёт связи оборваться, пока вкладка Suno в фоне. |
| `storage` | Хранит последнее состояние трека, чтобы окно расширения показывало его сразу при открытии. Локально, данные не отправляются. |
| Доступ к `suno.com` | Единственный сайт, с которым работает расширение: на его страницах читается плеер и с его вкладки берётся звук. |

**Удалённый код:** нет. Весь код в архиве, ничего не подгружается.

**Использование данных.** Отметить **«Содержимое веб-сайта» (Website content)**:
расширение читает со страницы Suno сведения о треке. Остальные категории — нет.
В пояснении указать, что данные не покидают устройство пользователя и уходят
только на `ws://localhost:6969`. Три подтверждения внизу соблюдаются:

- данные не продаются и не передаются третьим лицам за пределами одобренных случаев;
- данные не используются и не передаются в целях, не связанных с назначением расширения;
- данные не используются для определения кредитоспособности и выдачи займов.

## Примечание для проверяющего (поле «Instructions for reviewers»)

```
Расширению для работы нужна бесплатная программа с открытым исходным кодом,
запущенная на том же компьютере: она принимает данные на ws://localhost:6969 и
передаёт их в Discord. Без неё расширение показывает «не подключён» и ничего не
делает — это ожидаемое поведение, а не поломка.

Программа и установщик: https://github.com/e24x5-Fox/suno-discord-rpc/releases
Исходный код расширения: https://github.com/e24x5-Fox/suno-rpc-extension

Как проверить без установки программы: откройте suno.com, включите трек и
нажмите на значок расширения — в окне будут видны название трека, исполнитель и
позиция, прочитанные со страницы. Строка подключения при этом останется красной,
потому что принимать данные на компьютере некому.

Никаких внешних серверов расширение не использует: единственный адрес, к
которому оно обращается, — localhost.
```
