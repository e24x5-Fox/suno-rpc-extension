# 🎵 Suno → Discord RPC — расширение браузера

Читает плеер [suno.com](https://suno.com) и отдаёт данные о треке приложению
**Suno RPC**, которое показывает их в активности Discord.

> Само по себе расширение ничего не делает. Ему нужен запущенный сервер —
> десктопное приложение из репозитория
> **[suno-discord-rpc](https://github.com/e24x5-Fox/suno-discord-rpc)**.
> Там же лежит установщик.

---

## Что оно передаёт

- Название трека, исполнителя и ссылку на обложку
- Позицию и длительность воспроизведения (из `<audio>`-элемента страницы)
- Признак паузы
- Спектр звука вкладки для аудио-визуализаторов — захват через `tabCapture`,
  FFT считается в offscreen-документе

Данные уходят по WebSocket на `ws://localhost:6969` — этот порт слушает
Python-бэкенд приложения.

---

## Установка

Только **Chrome, Edge, Яндекс.Браузер, Opera** и другие Chromium-браузеры.

1. `chrome://extensions` → включить **«Режим разработчика»**
2. **«Загрузить распакованное расширение»** → выбрать папку этого репозитория
3. Запустить приложение **Suno RPC** (расширение работает только при запущенном сервере)
4. Открыть suno.com и начать воспроизведение

Нажатие на иконку расширения показывает состояние: `🟢 Подключён` — сервер
отвечает, `▶ Играет` — трек найден и передаётся.

### Firefox не поддерживается

И это не вопрос упаковки — упирается в три вещи сразу:

- **`offscreen`** — API только для Chromium. На нём держится весь FFT-анализ звука.
- **`tabCapture`** — в Firefox MV3 отсутствует.
- **`ws://` из контекста расширения Firefox не выпускает.** `moz-extension://`
  считается защищённым origin, и небезопасный WebSocket оттуда либо блокируется
  молча, либо повышается до `wss://`. Проверено на Firefox 154 сырым
  TCP-слушателем: прилетал TLS ClientHello, соединение закрывалось с кодом 1006,
  а расширение выглядело установленным, но мёртвым.

Для Firefox есть
[youtube-rpc-extension](https://github.com/e24x5-Fox/youtube-rpc-extension) —
второй источник активности, он ходит по обычному HTTP и потому работает.

## Сборка архива

```bash
python build.py
```

Кладёт `dist/suno-rpc-extension-<версия>.zip` — им расширение загружается в
Chrome Web Store или ставится на другой машине. Версия берётся из `version` в
`manifest.json`.

---

## Файлы

```
manifest.json     ← MV3, разрешения и точки входа
content.js        ← читает плеер со страницы suno.com
background.js     ← WebSocket-клиент + запуск захвата звука
offscreen.js      ← FFT-анализ, считается вне видимой страницы
offscreen.html
popup.html/js     ← окошко по клику на иконку
icons/
build.py          ← упаковка в .zip
```

Разбор селекторов DOM, формата передаваемых данных и типичных багов — в
[AI_GUIDE.md](https://github.com/e24x5-Fox/suno-discord-rpc/blob/main/AI_GUIDE.md)
основного репозитория.
